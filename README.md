# LÉON: Three Triggers

영화 *레옹: 더 프로페셔널*(1994)을 기반으로 한 인터랙티브 픽션(선택형 텍스트 게임) 기말 과제입니다.
하나의 사건을 **세 인물의 시점**으로 따라가며, 플레이어의 선택과 누적된 스탯에 따라 이야기가 갈라지고 **5개의 엔딩**으로 이어집니다.

- **레옹** — 2인칭("당신") 시점, 청부업자
- **마틸다** — 1인칭("나") 시점, 복수를 꿈꾸는 소녀
- **스탠스필드** — 3인칭 시점, 마약에 취한 DEA 요원

---

## 실행 방법

1. `LEON_Three_Triggers.html` 파일을 웹 브라우저로 엽니다 (더블클릭).
2. 별도 설치나 서버 없이 바로 플레이됩니다. (이미지가 보이려면 `images/` 폴더가 HTML과 같은 위치에 있어야 합니다.)

소스에서 다시 빌드하려면:
```
build.bat      (또는)   tweego --format=sugarcube-2 -o LEON_Three_Triggers.html src/
```

---

## 왜 Twee를 사용했나

Twine으로 인터랙티브 픽션을 만들 수 있지만, 비주얼 에디터(GUI) 대신 **Twee(플레인 텍스트 소스 포맷) + Tweego(CLI 컴파일러)** 조합을 선택했습니다.

- **버전 관리 / 코드 에디터** — 패시지를 텍스트로 다루니 VS Code에서 편집하고 변경 이력을 관리하기 좋습니다.
- **파일 분리** — 스토리를 시점별로 나눠 관리했습니다. (`src/passages/leon.twee`, `mathilda.twee`, `stansfield.twee`)
- **확장성** — 스토리 포맷으로 **SugarCube 2.37.3**을 사용해, 자바스크립트 매크로와 CSS를 자유롭게 붙일 수 있었습니다.

## 어떻게 사용했나 (주요 구현)

- **스탯 게이트 시스템** — 애착·규율·경계심·신뢰·분노·기술 6개 스탯을 두고, 특정 임계값을 넘으면 잠겨 있던 특별 선택지가 열립니다(`<<gate>>` 커스텀 매크로). 베데스다 RPG식 "조건부 선택지" 방식.
- **플래그 기반 엔딩** — 스탯이 직접 엔딩을 정하지 않고, 핵심 선택이 플래그로 누적되어 5개 엔딩(희생/조용/복수/빚/배드엔딩)으로 분기합니다.
- **선택지 효과 미리보기** — 각 선택지에 얻게 될 스탯 변화를 태그로 보여줍니다.
- **시네마틱 연출** — `<<timed>>`로 한 줄씩 드러나는 서스펜스, 타입라이터 효과, 레터박스/그레인/비네팅 스타일, 시점별 HUD, 이미지 클릭 확대(라이트박스), 소품 쇼케이스 등.

(시스템 설계 상세는 `SYSTEM.md`, 진행 기록은 `PROGRESS.md` 참고)

## 이미지는 어떻게 구했나

영화 스틸을 그대로 쓰지 않고, **전부 AI로 새로 생성**했습니다 (약 80장).

- OpenAI **gpt-image-1** 이미지 모델을 Python 스크립트(`tools/`)로 호출해 일괄 생성했습니다.
- 1994년 네오 누아르 / 35mm 필름 톤을 고정한 프롬프트로 전체 분위기를 통일했습니다.
- 실존 배우의 얼굴이나 영화 프레임은 복제하지 않고, 분위기만 살린 **오리지널 인물·소품**으로 만들었습니다.
- 미성년자·무기·폭력 묘사는 콘텐츠 정책에 맞게 **손·실루엣·오브젝트·POV** 등으로 우회해 표현했습니다.

## AI를 어떤 부분에 활용했나

- **이미지 생성** — 위에서 설명한 대로 모든 일러스트를 생성형 AI로 제작.
- **코드 / 기술 구현** — SugarCube 매크로, CSS 연출, 자바스크립트(라이트박스·HUD·게이트 등) 작성과 디버깅에 AI 코딩 어시스턴트를 활용.
- **시나리오 초안** — 한국어 내러티브와 대사의 초안 작성에 활용한 뒤, 직접 톤·디테일을 수정.

**직접 한 부분** — 전체 기획과 이야기 구조, 영화 각색 방향, 시점 설계, 엔딩 분기·밸런스, 아트 디렉션(어떤 장면에 어떤 이미지를), 그리고 모든 검수와 수정.
